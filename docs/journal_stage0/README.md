# Journal Stage 0 Artifacts

This directory stores reviewable, branch-tracked artifacts created during Stage 0 of the journal multi-horizon project.

## Files
- `station_manifest.csv`
- `split_manifest.json`
- `adjacency_snapshot.npz`
- `horizon_config.json`

## Purpose
- freeze the Shenzhen station roster and graph snapshot used by the journal line
- freeze the data split boundaries used for training, validation, calibration, and testing
- freeze the planned multi-horizon and quantile-grid configuration

## Notes
- These artifacts are generated by `scripts/journal/generate_stage0_audit.py`
- They should be regenerated only when the underlying data definition or journal configuration changes
